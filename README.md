# fbo-timeslot-filter

Библиотека для фильтрации поставок по дате таймслота.

## Правило
- Таймслот обязателен
- Дата берётся в таймзоне Asia/Krasnoyarsk (по умолчанию)
- Обрабатываются поставки с датой >= 2025-12-03 (включительно)
- Если таймслота нет — поставка пропускается, лог: "Нет таймслота"

## Env (опционально)
```env
TIMEZONE=Asia/Krasnoyarsk
MIN_DATE=2025-12-03
